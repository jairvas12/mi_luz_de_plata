# Luz de Plata

Proyecto frontend para la Evaluación Parcial 1.

## Estructura principal
- Tienda pública: inicio, catálogo, más vendidos, detalle de producto, envíos, conócenos, contacto, login, registro, carrito y blog.
- Administración: mantenedor de productos y usuarios.
- CSS externo separado por responsabilidad.
- JavaScript separado para productos, carrito, validaciones, usuarios y administración.
- Imágenes organizadas por categorías de productos.
